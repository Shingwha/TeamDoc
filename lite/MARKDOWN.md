# TeamDoc 支持的 Markdown 格式

这份表就是渲染器的规格。**唯一实现在 `lite/web/js/markdown.js`**(全站唯一渲染路径:文档编辑预览、
历史版本预览、云空间 `.md` 预览、`@文档` 引用浮层四处共用),编辑器里的 `/` 行首菜单与选区浮动工具栏
只提供其中一部分的快捷输入。改渲染行为时**必须同步这份表** —— 它是对外承诺,而 CLI / 导入脚本
(`teamdoc-cli` 的 `SKILL.md`)按它写正文。

渲染全部发生在**浏览器端**:服务端只存原始 Markdown 文本,不解析、不校验、不导出。

## 文本

| 写法 | 结果 |
|---|---|
| `**粗体**` `*斜体*` `~~删除线~~` | 粗体 / 斜体 / 删除线 |
| `` `行内代码` `` | 等宽胶囊 |
| `==高亮==` | 高亮底色(分隔符内侧不紧贴空白) |
| `H~2~O`、`x^2^` | 下标 / 上标(内容不含空白;`~~` 仍是删除线) |
| 单个换行 | 折行(`breaks` 打开,与 GFM 一致) |
| 空行 | 分段 |

## 标题、列表、引用、分割线

| 写法 | 结果 |
|---|---|
| `# 标题` ~ `###### 标题` | 六级标题(正文排版只到 h3 有独立字号) |
| `- 项` / `1. 项` | 无序 / 有序列表 |
| `- [ ] 项` / `- [x] 项` | 任务列表(checkbox 只读,勾选态由 `x` 决定) |
| `> 引用` | 引用块(左侧主色竖线) |
| `---` | 分割线 |

## 链接与引用

| 写法 | 结果 |
|---|---|
| `[文字](https://…)` | 新标签页打开(协议白名单:`http` `https` `mailto` `teamdoc` `/` `#`) |
| `[@标题](teamdoc://doc/{文档id})` | 文档引用 chip,点击弹预览浮层 |
| `[@名称](teamdoc://file/{文件id})` | 云空间文件引用 chip |
| `![名称](/api/files/{文件id}/download?inline=1)` | 内嵌图片(上传得到的地址;宽图按正文列宽收缩) |
| `[名称](/api/files/{文件id}/download)` | 附件链接 |

引用格式是**契约**,由编辑器与 CLI 共同生成,不要手写变体:引用里**只出现资源自己的 id**
(不带项目 —— 项目归属会变,引用必须跟着资源走)。服务端按这些形态判定文档反链与「被引用」徽标,
两种文件形态**都认**(`teamdoc://file/{fid}` chip 与 `/api/files/{fid}/download` 链接)——
徽标是删除前的安全网,漏认一种就等于少一层提醒。语法与解析的唯一来源是 `server/refs.py`
与 `web/js/ref.js`。

## 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|-------:|
| a      | b    | c      |
```

`:---` / `:---:` / `---:` 三档对齐都生效(坑:marked 输出的是 HTML `align` 属性,优先级低于
作者样式)。

## 代码块

````markdown
```python
print("hi")
```
````

按围栏语言自动高亮(Prism,语言包按需加载)。预览态每个代码块右上角有**语言角标**与**复制**按钮。

## 公式(KaTeX)

| 写法 | 结果 |
|---|---|
| `$E=mc^2$` | 行内公式 |
| `$$ x = \frac{-b \pm \sqrt{b^2-4ac}}{2a} $$` | 显示公式(独占一行的由块级收,写在段落中间的由行内收) |

**行内公式的三条定界要求**(缺一不可):开 `$` 后不紧贴空白、闭 `$` 前不紧贴空白、闭 `$` 后不是数字。
这样中文里最常见的美元金额不会被误判成公式:

| 写法 | 结果 |
|---|---|
| `价格 $5 和 $6 之间` | 原文照显(`$` 贴空白,不算公式) |
| `共 $3、$5 与 $7 三项` | 原文照显 |
| `定价 US$5 与 US$6 两档` | 原文照显(闭 `$` 后面紧跟数字) |
| `写成 $ x + y $ 不行` | 原文照显(内侧贴空白) |
| `价格 \$100` | 原文照显(`\$` 是转义的字面美元符号) |
| `公式 $E=mc^2$ 才是公式` | 渲染成公式 |

`$$…$$` 是**显示公式**的语义:独占一行时按块级渲染(内容可缩进、跨行,不受上面三条约束),
写在段落中间的 `$$a^2$$` 同样独立成块 —— 但那种写法要和散文抢地盘,所以也要求内侧不贴空白
(`成本 $$ 和 $$ 之间` 不会被当成公式)。

不支持 `\(…\)` 与 `\[…\]` 这两种 LaTeX 常规定界符。

## 图表(Mermaid)

````markdown
```mermaid
flowchart LR
  A[需求] --> B{评审}
  B -->|通过| C[开发]
```
````

支持的图型由 Mermaid 11 提供:流程图(flowchart)、时序图(sequenceDiagram)、类图(classDiagram)、
状态图(stateDiagram)、ER 图(erDiagram)、甘特图(gantt)、饼图(pie)、象限图、思维导图(mindmap)、
时间线(timeline)等。

- 编辑器 `/` 菜单里有「图表(Mermaid)」,插入一段可改的流程图骨架。
- 配色跟随站点主题令牌(与 6 个种子色、明暗都协调);换主题或换种子色时图表会重画。
- 图表是**浏览器端**渲染:`@文档` 引用浮层只取正文前 6000 字,截断正好落在围栏中间时会显示源码
  加一条「图表未渲染」的提示(截断的围栏本来就不是合法图表)。
- 语法写错时显示**源码 + 错误原因**,不改动正文,改好再看预览即可。
- 图表里的文字**不进全文搜索**(搜索只搜 Markdown 原文,围栏源码本身是搜得到的)。

## 脚注

```markdown
正文里的引用[^1],也可以用文字标签[^说明]。

[^1]: 定义写在文末即可,顺序不影响编号(编号按**引用**出现的先后)。
[^说明]: 定义可以跨行,
  续行缩进两格以上。
```

渲染为正文里一个上标角标 + 文末脚注区(每条带 ↩ 回跳链接;同一脚注被引多次时,每条引用各有一个 ↩)。
同一脚注可被多次引用,编号唯一。引用了但没定义时按普通文本显示(不留悬空角标)。

## 文内锚点(`#…`)

正文里的 `[文字](#某个id)` 与脚注的角标/回跳链接都由 `markdown.js` 接管:点击时**不让浏览器去改
`location.hash`**,而是自己滚动到目标并高亮落点。原因是全站用哈希路由(`#/p/{项目}/docs/{文档}`),
`#fn-1` 这种东西会被路由当成一条路由解析 —— 点下去的后果不是"没跳到位",而是**跳出文档**
(实测 hash 变成 `#/`、正在读的正文整个消失)。凡是渲染容器(`.markdown-body`:文档预览、历史
版本预览、云空间 md 预览、`@` 引用浮层)里的 `#` 链接都走这条通道,四处行为一致。

目标 id 由渲染产物提供(脚注是 `fn-N` / `fnref-N-k`);作者写的 `#某处` 若没有对应元素,点击
**静默不动**(不会报错,也不会把路由带跑)。`#/…` 开头的链接是站内路由本身,照常交给路由器。
指向站内文档/文件的链接请用 `teamdoc://` 引用格式,不要用锚点。

## 刻意不支持的

| 不支持的写法 | 原因 |
|---|---|
| 内联 HTML(`<div>` `<span>` `<details>` `<br>` …) | **一律转义**:多人协作场景下防 XSS 是硬要求。要新块级能力就加扩展语法,别开 HTML |
| `\(…\)` / `\[…\]` | 数学定界只认 `$…$` / `$$…$$` |
| 定义列表、Emoji 短码(`:smile:`) | 未实现(要加就在 `markdown.js` 的扩展列表里加,别再引新的第三方库) |
| 文档大纲 / 目录 | 不做(交互不佳);要目录就用脚注/标题锚点自行组织 |

## 维护者提示

- 语法全部集中在 `lite/web/js/markdown.js` 的 `marked.use({ extensions: [...] })` 一处;
  加语法 = 写一个 `{name, level, start?, tokenizer, renderer}`,`start` 是**可选**的优化提示
  (块级扩展的 `start` 只能报"真的块边界",否则 marked 会把段落切开再拼回,多塞一个换行 —— 脚注
  实现里踩过,见 `markdown.js` 的 `footnoteDef`)。
- 规则改了要同步:本文件、`lite/tests/test_markdown_render.py` 的用例表、
  以及 CLI 仓库的 `SKILL.md`。
- 快速验证:`lite/tests/test_markdown_render.py`(node,毫秒级,规则边界)+
  `lite/tests/test_markdown_diagram.py`(无头 Chrome,链路与离线)。
